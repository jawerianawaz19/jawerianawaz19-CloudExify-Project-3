Description

An interactive command-line Python Quiz Game with multiple bonus features. The game shuffles questions randomly, supports difficulty levels, includes a 30-second timer per question, tracks high scores, maintains a leaderboard, and shows a full answer review at the end.

 Features

- 15+ Python-related multiple choice questions
- Random question shuffling using `random` module
- Difficulty levels: Easy / Hard / Mixed
- 30-second timer per question
- Score calculation with percentage and grade (A–F)
- High score system (saved in `highscore.txt`)
- Player name input + Leaderboard (Top 10 saved in `leaderboard.txt`)
- Full answer review after quiz
- Play again option
- Input validation for answers


How to Play

Enter your name.
Select difficulty (1 = Easy, 2 = Hard, 3 = Mixed).
Press Enter to start the quiz.
Answer each question with A, B, C, or D within 30 seconds.
After all questions, view your score, grade, answer review, and leaderboard.
Choose to play again or exit.
